
# Desenvolvimento de uma fresadora CNC para confecção de antenas planares e PCIs

Este repositório contém os arquivos de modelagem, código-fonte e artefatos utilizados no desenvolvimento de uma **fresadora CNC de pequeno porte**, criada para a fabricação de **antenas planares** e **circuitos impressos (PCIs)** em ambiente acadêmico. O projeto foi desenvolvido como Trabalho de Conclusão de Curso no **Instituto Federal de Santa Catarina (IFSC) -- Câmpus São José**.

## Objetivo do Projeto

Construir uma fresadora CNC acessível, utilizando componentes de **baixo
custo**, **fácil aquisição** e **plataformas abertas**, permitindo:

-   Produção de antenas impressas;
-   Fabricação de PCIs simples por fresamento;

## Características Principais

-   Arquitetura: **CNC vertical de pórtico fixo**.
-   Eixos X, Y e Z controlados por motores **NEMA 17**.
-   Estrutura construída com **perfis de alumínio estrutural**.
-   Guias lineares com **eixos retificados de 12 mm e rolamentos
    LM12UU**.
-   Movimento por **fusos trapezoidais TR8** com castanhas
    **antifolga**.
-   Spindle baseado no motor **775** com suporte **ER11**.
-   Eletrônica simples:
    -   **Arduino Uno**
    -   **CNC Shield V3**
    -   **Drivers A4988**
    -   **Chaves de fim de curso**
-   Firmware: **Grbl** (open-source).
-   Compatível com softwares de envio de G-code, como **Universal Gcode Sender**.
